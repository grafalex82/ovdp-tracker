# Итоговая проверка MVP

Дата: 6 ноября 2026 года. Изменение OpenSpec: `initial-bond-portfolio-mvp`, задачи 7.1 и 7.2.

## Автоматический сквозной сценарий

Добавлен [test_end_to_end.py](../tests/test_end_to_end.py). Тест использует временный SQLite-файл через `tmp_path`,
публичный API `Database` и HTTP-маршруты приложения. Только транспорт НБУ заменён фиксированным ответом;
разбор справочника, подпись черновика, валидация и сохранение выполняются обычным кодом приложения.

Сценарий проверяет:

- Загрузку нового ISIN без записи черновика и две исторические покупки с разными датами, ценами и банками.
- Один выпуск, один календарь с разными купонами, одну строку портфеля и отсутствие прав на купоны до покупки.
- Отдельные подтверждения одного события для разных покупок и частичную продажу.
- Исправление цены покупки, общей ставки и сумм купонов с сохранением фактических выплат и соседней покупки.
- Месячные итоги по плановым и фактическим датам, пустые месяцы и отсутствие продаж в таблице выплат.
- Точные остатки, прибыль, обе годовые доходности, долю в портфеле и родительские крошки.
- Погашение первой покупки, повторное создание приложения и соединений с прежним файлом.
- Явное удаление первой покупки с её историей без изменения выпуска, календаря, банков и соседней покупки.

Независимые эталоны перед погашением: остаток **12 бумаг**, себестоимость **11 670,00 UAH**,
номинал **12 000,00 UAH**, прибыль за весь срок **3 530,00 UAH**, XIRR **11,4851720692%**,
простая годовая доходность **11,9510733658%**, точный знаменатель **10 781 040 UAH·дней**.
После погашения первой покупки ожидаемая прибыль оставшейся покупки равна **925,00 UAH**;
после удаления первой покупки сохраняются её соседка с остатком **5 бумаг** и фактическим купоном **400,00 UAH**.

## Полный набор тестов и установка

```powershell
python -m pytest --basetemp .pytest_cache/final-suite
```

Результат: **694 passed**, 71,68 секунды, Python 3.11.15, pytest 9.1.1, Windows.
Явный `--basetemp` нужен в ограниченной среде проверки, где стандартный временный каталог pytest недоступен.
Обычная команда проекта остаётся `python -m pytest`.

Команда `python -m pip install -r requirements-dev.txt --dry-run --no-index` подтвердила наличие всех
зафиксированных зависимостей без установки пакетов. README исправлен: virtualenv и Docker не обязательны.

## Проход в Chrome

Использован отдельный экземпляр с временной базой в `.pytest_cache/`; рабочая база `instance/` не открывалась.
Выполнена точка входа `ovdp_tracker.__main__` с проверкой её штатных параметров: `127.0.0.1:5000`,
debug, debugger, reloader и dotenv выключены. Для браузерной проверки заменены только путь базы и порт на 5055,
поскольку штатный экземпляр пользователя уже работал на порту 5000.

| Проверка | Результат |
| --- | --- |
| Пустой запуск | Пустой портфель без авторизации и демонстрационных операций. |
| Живой НБУ | `UA4000239081`: получены номинал 1000 UAH, ставка 16,44%, восемь купонов и отдельное погашение. |
| Сохранение черновика | Ввод даты, цены, количества и банка сохранился после загрузки; покупка записана явно. |
| Отсутствующий ISIN | Живой справочник не содержал `UA4000228381`; показана ошибка поиска без частичного импорта. |
| Недоступный НБУ | Смоделирован отказ внешнего транспорта; штатная ошибка предлагает повтор или ручной ввод. |
| Повторная покупка без НБУ | Сохранены общие реквизиты и календарь; одна строка UAH с количеством 15. |
| Ручной ввод без НБУ | Сохранён новый USD-выпуск с купоном 85 USD; портфель открылся в USD. |
| Ошибка точности | Цена `1000.005` отклонена; все поля сохранены; после исправления на `990` запись успешна. |
| Защита после ошибки | Переход во «Выплаты» вызвал диалог; «Остаться» сохранило черновик. |
| Редактирование покупки | Изменённая цена вызвала диалог; восстановление исходной цены сняло предупреждение. |
| Общая правка | Номинал 0 отклонён; подтверждённый уход из изменённой формы не сохранил правку. |
| Навигация | Три вкладки выделяют текущий раздел; крошки выпуска, покупки и редакторов ведут к родителям. |
| Месячные выплаты | UAH: август 2026 — 822,00; февраль 2027 — 1233,00; промежуточные месяцы нулевые. |
| Статистика без НБУ | За весь период покупки UAH равны 14 300,00; доходности сохраняют полный горизонт. |
| Узкий экран | При ширине 320 px доступны навигация, поля, купонный редактор, диалог и сохранение. |
| Широкие таблицы | Таблицы прокручиваются внутри блоков; ширина страницы не превышает ширину области просмотра. |
| Перезапуск | Все два выпуска, 11 событий и три покупки сохранены; полный снимок публичного API совпал. |

Недоступность НБУ моделировалась только для тестового экземпляра на границе внешнего запроса;
системные сетевые настройки не менялись. Браузерная проверка дополняет независимые числовые тесты.
После проверки временное изменение размера браузера снято, тестовый сервер остановлен.
