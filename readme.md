# ОВДП Трекер

«ОВДП Трекер» помогает вести личный портфель облигаций внутреннего государственного займа Украины:
сохранять покупки, видеть количество бумаг и проверять расписание купонов и погашений.
Приложение работает в браузере на вашем компьютере. Сохранённые покупки остаются доступны после перезапуска.

## Что можно делать

- Добавлять покупки с датой, ценой, количеством облигаций и банком.
- Загружать сведения об облигации и календарь выплат из НБУ по ISIN или вводить их вручную.
- Смотреть портфель отдельно в гривнах, долларах США и евро.
- Объединять несколько покупок одного выпуска в одну позицию, сохраняя подробности каждой покупки.
- Просматривать общий календарь выпуска и причитающиеся выплаты каждой покупки.
- Смотреть предстоящие, просроченные и подтверждённые выплаты по всем покупкам в отдельном разделе.
- Смотреть статистику денежных операций за выбранный период отдельно по валютам.
- Подтверждать фактические дату и сумму купонов и погашений выбранной покупки.
- Исправлять дату и сумму уже подтверждённой выплаты.
- Записывать полные и частичные продажи выбранной покупки.
- Удалять покупку со всей её историей после отдельного подтверждения.
- Открывать действующие и закрытые позиции.

Приложение развивается. Ограничения текущей версии перечислены в разделе [«Что пока недоступно»](#что-пока-недоступно).

## Установка и запуск

Понадобятся Python 3.11 с pip и браузер. Скачайте исходники с
[GitHub](https://github.com/grafalex82/ovdp-tracker) или клонируйте репозиторий:

```powershell
git clone https://github.com/grafalex82/ovdp-tracker.git
cd ovdp-tracker
```

Откройте терминал в папке проекта. Создайте отдельное окружение и активируйте его:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

В Linux и macOS вместо последней команды выполните `source .venv/bin/activate`.
Если команда `python` недоступна, используйте `python3`.

Установите зависимости и запустите приложение:

```powershell
python -m pip install -r requirements.txt
python -m ovdp_tracker
```

Откройте [http://127.0.0.1:5000/](http://127.0.0.1:5000/) в браузере.
При первом запуске портфель пуст — начните с кнопки **«Добавить облигацию»**.

Пока пользуетесь приложением, оставляйте терминал открытым. Для остановки нажмите `Ctrl+C`.
При следующем запуске откройте папку проекта, активируйте окружение и выполните `python -m ovdp_tracker`.
Повторно устанавливать зависимости для обычного запуска не нужно.

Интернет нужен для установки и загрузки новых сведений из НБУ.
Просматривать сохранённые покупки и вводить облигации вручную можно без интернета.

## Как устроен портфель

**ISIN** — идентификатор выпуска облигаций. Все покупки с одинаковым ISIN объединяются в одну строку портфеля.
Например, если вы купили 10 бумаг одного выпуска, а затем ещё 5 в другом банке, в портфеле будет одна позиция
с 15 бумагами. Даты, цены и банки обеих покупок можно посмотреть внутри неё.

На странице **«Портфель»** выберите **«Валюта выпуска»**: UAH, USD или EUR.
По умолчанию показываются гривневые облигации; при выборе другой валюты список обновляется.
Если нужной позиции не видно, сначала проверьте выбранную валюту.

| Колонка | Что показывает |
| --- | --- |
| ISIN | Выпуск облигаций; нажмите на него, чтобы открыть подробности. |
| Количество | Общий остаток бумаг по всем покупкам выпуска. |
| Купон и дата купона | Ближайший ожидаемый положительный купон на одну облигацию и его дату. |
| Осталось купонов | Число общих купонных дат от сегодня включительно с ожидаемой выплатой действующей покупки. |
| Погашение | Плановую дату погашения выпуска. |
| Доходность | Номинальную ставку выпуска из НБУ, если она известна. |

Значение в колонке **«Доходность»** — справочная ставка выпуска; **«Не указана»** означает, что она отсутствует.
Отдельная колонка **«Ожидаемая доходность, % годовых»** показывает XIRR действующих покупок этого ISIN.
**«Нет будущего купона»** означает, что подходящего предстоящего купона нет; погашение смотрите отдельно.
Одна дата считается один раз независимо от числа покупок и бумаг. Полностью подтверждённые и нулевые
купоны не входят в оставшееся число; при подтверждении только одной покупки общая дата остаётся в счётчике.
Прошедшие неподтверждённые купоны сохраняются в выплатах покупок, но не входят в число оставшихся дат.

## Добавить покупку

Каждую фактически совершённую покупку добавляйте отдельно, даже если такой ISIN уже есть в портфеле.

### Загрузить облигацию из НБУ

1. На странице портфеля нажмите **«Добавить облигацию»**.
2. Оставьте способ добавления **«Подтянуть из НБУ»**.
3. Введите полный ISIN из 12 символов и дождитесь загрузки.
4. Проверьте валюту, номинал, дату погашения и расписание выплат в блоке **«Параметры выпуска»**.
5. Заполните **«Параметры покупки»** по таблице ниже.
6. Нажмите **«Сохранить покупку»**.

После сохранения откроется портфель в валюте добавленной облигации с сообщением **«Покупка сохранена»**.
Загрузка сведений из НБУ сама по себе покупку не сохраняет.

| Поле покупки | Что ввести |
| --- | --- |
| Дата покупки | Дату покупки. Изначально выбрана сегодняшняя; временно разрешены прошедшие и будущие даты. |
| Цена одной облигации | Фактическую цену одной бумаги в валюте выпуска. |
| Количество облигаций | Целое положительное число купленных бумаг. |
| Банк | Название банка: выберите из подсказок или введите новое. |

Цену вводите с точкой или запятой, максимум с двумя знаками после разделителя: например, `995,50`.
Она должна быть положительной. Проверка запрета будущих дат покупок и продаж временно отключена.
Покупка по-прежнему не может быть позже погашения, а продажа — раньше покупки.
Название нового банка появится в подсказках после сохранения покупки.

Если загрузка не удалась, проверьте ISIN и нажмите **«Загрузить повторно»**.
При необходимости переключитесь на ручной ввод.

### Ввести облигацию вручную

1. Нажмите **«Добавить облигацию»** и выберите **«Ввести вручную»**.
2. Укажите ISIN, номинал одной облигации и валюту выпуска.
3. Для каждого купона нажмите **«Добавить купон»**, выберите дату и введите сумму **на одну облигацию**.
4. Проверьте календарь и дату погашения.
5. Заполните дату, цену, количество и банк покупки, затем нажмите **«Сохранить покупку»**.

Включайте полный известный календарь, в том числе купоны до вашей покупки. Они останутся в сведениях о выпуске,
но не будут показаны как причитающиеся этой покупке выплаты.
У разных купонов могут быть разные суммы; нулевая сумма допустима. Даты купонов не должны повторяться.

Кнопка **«Сортировать по дате»** упорядочивает строки вместе с суммами.
**«Удалить купон»** убирает выбранную строку. Дату можно набрать с клавиатуры или выбрать в календаре.

Для ручного ввода действуют следующие правила:

- При наличии купонов датой погашения становится дата последнего купона.
- Для облигации без купонов оставьте список пустым и заполните появившееся поле **«Дата погашения»**.
- Сумма погашения одной бумаги равна её номиналу.
- Ставка, дата выпуска и вид облигации вручную не запрашиваются.

Если реальное погашение не совпадает с последним купоном, используйте загрузку из НБУ.
Переключение способов добавления сохраняет введённые вручную строки и параметры покупки,
пока форма остаётся открытой.

### Докупить уже сохранённый выпуск

1. Откройте **«Добавить облигацию»** и введите ISIN, который уже есть в портфеле.
2. Проверьте показанные сохранённые реквизиты и календарь.
3. Укажите параметры новой покупки и сохраните её.

Номинал, валюта и календарь общие для всех покупок одного выпуска, поэтому в повторной покупке они недоступны
для редактирования. Каждая покупка сохраняет собственные банк, дату, цену и количество.
Для докупки без интернета выберите **«Ввести вручную»**: известный ISIN использует сохранённые сведения.

Если данные НБУ отличаются от сохранённых, приложение покажет предупреждение и использует сохранённый вариант.
Добавление покупки не обновляет общие реквизиты выпуска.

## Посмотреть облигацию и её покупки

Нажмите **ISIN** в портфеле. Откроется страница выпуска со следующими сведениями:

- Общие параметры: валюта, номинал, остаток бумаг, погашение и известные сведения о ставке и выпуске.
- **«Общий календарь выпуска»**: даты и типы выплат, сумма на одну бумагу, количество во владении на дату
  события, общая плановая сумма и выплаты каждой покупки в столбик внутри одной ячейки.
- **«Все покупки»**: банк, дата, цена, стоимость, исходное количество, остаток и статус каждой покупки.

Чтобы посмотреть одну покупку, нажмите **«Покупка №…»**.
Стоимость покупки равна цене одной облигации, умноженной на купленное количество.
Например, 10 бумаг по `995,50` дают стоимость `9 955,00` в валюте выпуска.

Для возврата используйте ссылки над содержимым страницы: **«Портфель»**, ISIN и **«Покупка №…»**.
На странице выпуска также есть ссылка в портфель его валюты.
На узком экране широкие таблицы можно прокручивать по горизонтали.

## Исправить общие реквизиты облигации

Откройте ISIN в портфеле и нажмите **«Редактировать облигацию»**. Форма меняет общие параметры выпуска
для всех его покупок: валюту, номинал, сведения о выпуске, купонные даты с отдельными суммами и погашение.
ISIN остаётся прежним. Дата и сумма погашения задаются отдельно, независимо от последнего купона;
можно добавить, удалить или отсортировать купоны, включая прошлые и нулевые.

Нажмите **«Сохранить облигацию»**, чтобы применить исправление и вернуться в портфель выбранной валюты.
Приложение проверяет истории всех покупок: если хотя бы одна становится недопустимой, всё изменение
отклоняется. Введённые значения остаются в форме с защитой несохранённых изменений.
**«Отмена»** и крошки **«Портфель / ISIN / Редактирование облигации»** позволяют выйти из редактора.

Цены, даты, количества, банки и продажи покупок сохраняются. Неподтверждённые ожидания пересчитываются
по исправленному календарю; фактические поступления не перезаписываются.
Например, изменение купона с `80,00` на `85,00` увеличит ожидание покупки из 5 бумаг с `400,00` до `425,00`,
а уже подтверждённые `795,00` другой покупки останутся прежними. Суммы соседних дат не меняются.
События с неизменными типом и датой сохраняют идентификаторы и связи с подтверждениями.
Удалить или перенести дату события с фактической выплатой любой покупки этого ISIN нельзя.
Его плановую сумму можно исправить без изменения факта.

## Читать календарь и выплаты

Общий календарь относится ко всему выпуску. Количество купонов включает весь календарь, в том числе прошлые
и нулевые купоны; погашение считается отдельно. Каждая строка таблицы содержит:

- **Дату** и **тип выплаты** — купон или погашение.
- **На одну облигацию** — собственную сумму события общего календаря.
- **Количество на дату события** — суммарное количество бумаг, которым причитается выплата по истории покупок.
- **Общую плановую сумму** — сумму на одну бумагу, умноженную на это количество.
- **Выплаты покупок** — список в столбик внутри одной ячейки: ссылка на покупку, её количество и плановая сумма;
  фактические дата, сумма и статус показаны отдельно при наличии подтверждения.

Общий план включает подтверждённые покупки и покупки, закрытые после даты события. Это план по календарю,
а не сумма полученных или ещё ожидаемых денег. Например, для 10 и 5 бумаг с купоном `80,00` общий план равен
`1200,00`. Подтверждённые `795,00` вместо плановых `800,00` первой покупки показываются в её пункте отдельно;
у второй остаётся неподтверждённый план `400,00`, доплата первой покупке не ожидается.
События до всех покупок остаются в календаре с нулевыми количеством и общим планом и пояснением отсутствия
причитающихся выплат. Для будущих дат расчёт использует сохранённую историю.

В карточке конкретной покупки таблица **«План и факт покупки»** показывает её собственные даты, количества,
плановые суммы и фактические поступления.

Например, купон `80,00` на одну бумагу при количестве 10 даёт плановую выплату `800,00`.
Купон и погашение в один день отображаются отдельными строками.
Даты до покупки не создают ей ожиданий или требований подтверждения. Для операций одного дня порядок такой:
покупка, купон, продажи, погашение. Продажа 3 из 10 бумаг до купона `80,00` уменьшает ожидание до `560,00`,
а продажа после купона сохраняет прошлое ожидание `800,00`. Если следующий купон равен `85,00`,
на оставшиеся 7 бумаг ожидаются `595,00`. Погашение использует собственную сумму события, которая может
отличаться от номинала. Для остатков 7 и 5 бумаг ближайший общий купон по `80,00` даёт `960,00`.

**«Не подтверждено»** означает положительную выплату сегодня или в будущем без записанного факта.
Если плановая дата строго раньше сегодняшней локальной даты, она отмечается **«Требует подтверждения»**.
Отметка видна отдельно от состояния покупки и позиции, включая закрытые позиции с историческими купонами.
Просрочка не означает получение денег и не увеличивает число оставшихся купонов. Нулевой купон
не требует подтверждения; события до покупки и без причитающегося количества не создают просрочку.
**«Подтверждено»** означает сохранённые фактические дату и сумму, которые могут отличаться от плана.
Наступление плановой даты само по себе
не подтверждает выплату и не закрывает позицию. Для нулевого купона подтверждение не требуется.

## Раздел «Выплаты»

Откройте верхнюю вкладку **«Выплаты»**. Она показывает три списка: прошедшие выплаты,
требующие подтверждения, ближайшие выплаты с сегодняшнего дня и подтверждённую историю.
Покупка и событие занимают отдельную строку, даже когда несколько покупок относятся к одной дате.
Исторические купоны закрытых покупок также остаются доступны; продажи в эти списки не входят.

Выберите UAH, USD или EUR и при необходимости укажите границы периода, затем нажмите **«Показать»**.
Обе границы включены; пустое поле оставляет период открытым с соответствующей стороны.
Неподтверждённые выплаты отбираются по плановой дате, подтверждённые — по фактической.
Например, купон с планом на 30 июня и фактом 1 июля попадёт в июльскую историю, а не в июньскую.
Нулевой купон не требует подтверждения; события без прав покупки не создают выплату.

В строке доступны банк покупки, плановые дата и сумма, фактические дата и сумма при наличии, статус и ссылки на ISIN,
покупку и подтверждение или исправление. Подтверждение одной покупки не меняет ожидание другой.
Месячная таблица выплат будет добавлена отдельно.

## Подтвердить получение выплаты

В карточке покупки или в её пункте общей таблицы ISIN нажмите **«Подтвердить выплату»** рядом с нужным
купоном или погашением. Форма показывает покупку, тип события, плановые дату, количество и общую сумму.
В полях первоначально предложены плановая дата и общая сумма этой покупки, а не сумма на одну бумагу.

Укажите фактические дату и сумму поступления. Дата должна быть не раньше покупки и не позже сегодняшней
локальной даты; она может отличаться от плановой. Сумма должна быть положительной, с максимум двумя знаками
после точки или запятой. Например, вместо плановых `800,00` на 1 июня можно подтвердить `795,00` на 3 июня.
Если плановая дата ещё в будущем, для уже полученного поступления укажите его фактическую прошедшую дату.

После сохранения открывается карточка покупки с сообщением **«Выплата подтверждена»** и фактическими
датой/суммой в таблице. Подтверждение заменяет только ожидание выбранной покупки: доплата до плана
не ожидается, реквизиты общего календаря и выплаты соседних покупок сохраняются. Обновление страницы
и повторная отправка не создают второе поступление и не изменяют уже сохранённые дату и сумму.
Для изменения сохранённых даты и суммы используйте отдельное действие **«Исправить выплату»**.

Можно восстанавливать исторические поступления, включая купон полностью проданной покупки, если на дату
события она владела бумагами. Даты до покупки, события без прав и нулевые купоны подтвердить нельзя.
Подтверждение погашения закрывает весь непроданный остаток выбранной покупки; продажа после фактического
погашения недопустима. Если сохранённая история противоречит подтверждению, оно отклоняется целиком.

При ошибке проверки или записи форма сохраняет введённые значения и защиту несохранённых изменений.
Ссылки отмены и хлебные крошки позволяют уйти с формы; изменённый ввод требует подтверждения ухода.

## Исправить подтверждённую выплату

В карточке покупки или в её пункте общего календаря ISIN нажмите **«Исправить выплату»** рядом с фактом.
Форма предлагает сохранённые фактические дату и сумму. Измените их и нажмите **«Сохранить исправление»**:
откроется карточка покупки с сообщением **«Выплата исправлена»**. Это замена существующего поступления,
его связь с покупкой и событием сохраняется; второе поступление не создаётся.

Дата должна быть от даты покупки до сегодняшней локальной даты включительно, сумма — положительной
и максимум с двумя знаками после разделителя. Например, дату купона можно перенести с `2025-06-30`
на `2025-07-01`, сохранив фактическую сумму `795,00` вместо плановых `800,00`.
Общий календарь ISIN, факты других покупок и продажи сохраняются. Перенести фактическое погашение
раньше сохранённой продажи нельзя; продажи того же дня учитываются до погашения, купон — до продажи.
Противоречие истории или ошибка записи откатывает исправление целиком, сохраняя ввод и защиту формы.

Общая правка купона, например с `80,00` до `85,00` на бумагу, сохраняет исправленный факт и его дату.
Событие с подтверждением любой покупки нельзя удалить через редактор выпуска.
Доходности используют исправленные фактические даты и суммы; месячные итоги появятся в разделе выплат позже.

## Удалить ошибочное подтверждение выплаты

В карточке покупки или общем календаре ISIN нажмите **«Исправить выплату»** рядом с нужным подтверждением,
затем **«Удалить выплату»** под формой. Действие доступно и для закрытой покупки; для диалога нужен JavaScript.
Проверьте сохранённые тип выплаты, фактические дату и сумму с валютой и подтвердите удаление.
**«Отмена»** или Escape закрывают диалог и сохраняют введённые правки. При удалении эти правки не применяются;
откроется карточка покупки с сообщением об успехе. При ошибке черновик остаётся в форме.

Удаляется только выбранное подтверждение. Общий календарь, продажи и другие фактические выплаты сохраняются.
Если право на выплату остаётся, она снова ожидается или требует подтверждения. После удаления погашения
восстанавливается непроданный остаток и покупка может снова стать действующей. После досрочного погашения
неподтверждённый поздний купон остаётся скрытым, пока сохраняется подтверждение погашения.

## Действующие и закрытые позиции

Используйте ссылки **«Действующие позиции»** и **«Закрытые позиции»** внутри портфеля.
При переключении выбранная валюта сохраняется.

Позиция считается закрытой, когда не осталось бумаг ни в одной её покупке.
Если часть покупок закрыта, а в других остались бумаги, выпуск остаётся действующим;
закрытые покупки доступны на странице выпуска. Одна лишь прошедшая дата погашения не закрывает позицию.
Подтверждение погашения закрывает остаток только выбранной покупки; другая покупка того же ISIN
с непроданными и непогашенными бумагами сохраняет позицию действующей.

## Записать продажу

Откройте нужную покупку и нажмите **«Добавить продажу»**. Укажите дату совершённой продажи,
целое количество и цену одной бумаги в валюте выпуска. После сохранения на странице покупки
появятся продажа и её выручка, а остаток и последующие плановые выплаты пересчитаются.
Другие покупки того же выпуска не затрагиваются.

Дата продажи может быть будущей, но не может предшествовать покупке. Приложение проверяет также
последующие продажи: запись задним числом не должна создавать отрицательный остаток.
В день купона сначала учитывается купон, затем продажа; в день фактического погашения продажа
учитывается до погашения.

## Удалить ошибочную продажу

В карточке покупки найдите нужную продажу и нажмите **«Редактировать»**. Внизу редактора доступна кнопка
**«Удалить продажу»**. В списках и форме новой продажи этой кнопки нет; для диалога нужен JavaScript.
Удаление доступно также для продаж закрытой покупки.

В подтверждении показаны сохранённые ISIN, покупка, дата продажи, количество, цена и выручка с валютой.
**«Отмена»** или Escape закрывают диалог, сохраняя введённые правки. Эти правки не применяются при удалении.
Кнопка **«Удалить сохранённую продажу»** удаляет только выбранную запись без возможности восстановления
и открывает карточку покупки с сообщением об успехе.

Остаток и неподтверждённые выплаты пересчитываются: удаление продажи 3 из 10 бумаг возвращает остаток 10
и увеличивает последующий ожидаемый купон по 80 UAH с 560,00 до 800,00 UAH. Полностью проданная покупка
снова становится действующей, если нет фактического погашения. Подтверждённые суммы и даты выплат сохраняются
без ожидания доплаты; подтверждённое погашение продолжает закрывать покупку. Остальные продажи, покупки,
общие реквизиты ISIN, календарь и банки сохраняются. При ошибке удаления изменения откатываются.
Прибыль и годовые доходности используют исправленную историю.

## Прибыль и годовая доходность

Портфель показывает итоги отдельно для выбранной валюты; детали ISIN и карточка покупки содержат те же
показатели для соответствующих покупок. Полученная прибыль на сегодня — подтверждённые купоны плюс выручка
продаж и подтверждённые погашения за вычетом исходной стоимости выбывших бумаг. Стоимость оставшихся бумаг
из неё не вычитается. В деталях ISIN полученные купоны и неподтверждённые купоны и погашения показаны отдельно.

Прибыль за весь срок включает фактические поступления и продажи вместе с прогнозом неподтверждённых выплат
за вычетом полной стоимости покупки. Подтверждение заменяет прогноз только соответствующей покупки и события.
Доходности и прогноз прибыли позиции и портфеля используют полную историю действующих покупок; полностью
закрытые покупки исключены, но их полученная прибыль остаётся в общем фактическом итоге. В карточке закрытой
покупки доходности становятся фактическими, когда все причитающиеся выплаты подтверждены; просроченные
неподтверждённые выплаты делают показатели предварительными.

XIRR — годовая ставка `r`, при которой сумма `CFᵢ / (1 + r)^((dᵢ − d₀) / 365)` равна нулю. Вложения
отрицательны, поступления положительны, для фактов используются их даты и суммы, для остальных выплат —
плановые. Простая годовая доходность равна `100 × прибыль / Σ(себестоимость части × дни владения / 365)`;
для каждой проданной или погашенной части учитывается её собственный срок. Суммы и сроки покупок объединяются
до вычисления показателей, проценты не усредняются. Доходности округляются только при отображении до двух
знаков; если ставка не определяется, показывается причина, а остальные результаты сохраняются.
Обе доходности относятся ко всему сроку исходных покупок, а не к текущей рыночной YTM: текущая рыночная цена
не вводится и рыночная стоимость не рассчитывается.

## Статистика операций

В верхней вкладке **«Статистика»** выберите валюту и текущий месяц, квартал, год, весь период или
произвольные даты. Границы включены; пустая граница произвольного диапазона не ограничивает период.
Покупки и продажи относятся к датам операций, подтверждённые выплаты — к фактическим датам, независимо
от даты ввода. Неподтверждённые выплаты не включаются в полученные суммы. Покупки, купоны, погашения
и выручка от продаж показаны раздельно; погашение и выручка включают возврат вложений, а не только прибыль.
Полученная прибыль периода учитывает купоны и результат выбытия до сегодняшнего дня. Сохранённые продажи
с будущими датами показываются в операциях выбранного периода, но ещё не входят в полученную прибыль.
Доходности и прогноз прибыли действующих покупок всегда рассчитываются за весь срок, независимо от фильтра.

## Удалить покупку

В карточке нужной покупки нажмите **«Редактировать покупку»**, затем **«Удалить покупку»** под формой.
Откроется отдельная страница с ISIN, банком, датой, стоимостью покупки и числом удаляемых продаж
и подтверждений выплат. Проверьте выбранную покупку.
**«Отмена»** возвращает к редактированию без изменений.

Кнопка **«Удалить покупку и всю её историю»** навсегда удаляет покупку, её продажи и фактические
подтверждения выплат. Восстановления истории в приложении нет. Удалённые данные исключаются из расчётов;
после удаления откроется портфель в валюте покупки с сообщением об успехе.

Общие реквизиты ISIN, календарь, банки и соседние покупки с их подтверждениями сохраняются.
После удаления последней покупки позиция исчезает из действующего и закрытого портфеля;
при следующей покупке того же ISIN используются сохранённые реквизиты и календарь.

## Ошибки и несохранённые изменения

Если покупка не сохраняется, прочитайте сообщение возле поля, исправьте значение и нажмите
**«Сохранить покупку»** ещё раз. Введённые данные, включая незавершённые строки купонов, сохраняются в форме.

При уходе с изменённой формы по ссылке или через **«Отмена»** появляется выбор:

- **«Остаться»** — продолжить заполнение; нажатие Escape также оставляет форму открытой.
- **«Выйти без сохранения»** — перейти на выбранную страницу и отказаться от изменений.

При обновлении или закрытии вкладки браузер может запросить подтверждение ухода.
Автоматического восстановления черновика после закрытия страницы нет — завершайте ввод кнопкой
**«Сохранить покупку»**. Загрузка данных из НБУ также оставляет несохранённый черновик.

## Что пока недоступно

- Месячная таблица выплат, оценка остатков и распределение по срокам погашения.
- Отдельный режим сценарного планирования покупок.
