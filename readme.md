# Трекер ОВДП

Небольшой пет-проект для личного учёта облигаций внутреннего государственного займа Украины (ОВДП). Помогает отслеживать покупки, погашения и прибыль, а также планировать будущие вложения.

Основные возможности:

- Добавление облигаций с датой покупки, стоимостью, количеством и датой погашения.
- Учёт полученных выплат и расчёт ожидаемой прибыли.
- Статистика прибыли и доходности за выбранные периоды.
- Планирование будущих покупок и ожидаемых поступлений.

Проект рассчитан на одного пользователя. Приоритет — простые и понятные решения, минимум зависимостей и архитектуры, только необходимой для текущих задач.

Описание требований и изменений хранится в `openspec/`, контекст проекта и правила работы — в `openspec/config.yaml`.
