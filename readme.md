# ОВДП Трекер

«ОВДП Трекер» помогает вести личный портфель облигаций внутреннего государственного займа Украины:
сохранять покупки, видеть количество бумаг и проверять расписание купонов и погашений.
Приложение работает в браузере на вашем компьютере. Сохранённые покупки остаются доступны после перезапуска.

## Что можно делать

- Добавлять покупки с датой, ценой, количеством облигаций и банком.
- Загружать сведения об облигации и календарь выплат из НБУ по ISIN или вводить их вручную.
- Смотреть портфель отдельно в гривнах, долларах США и евро.
- Объединять несколько покупок одного выпуска в одну позицию, сохраняя подробности каждой покупки.
- Просматривать общий календарь выпуска и причитающиеся выплаты каждой покупки.
- Записывать полные и частичные продажи выбранной покупки.
- Удалять покупку со всей её историей после отдельного подтверждения.
- Открывать действующие и закрытые позиции.

Приложение развивается. Ограничения текущей версии перечислены в разделе [«Что пока недоступно»](#что-пока-недоступно).

## Установка и запуск

Понадобятся Python 3.11 с pip и браузер. Скачайте исходники с
[GitHub](https://github.com/grafalex82/ovdp-tracker) или клонируйте репозиторий:

```powershell
git clone https://github.com/grafalex82/ovdp-tracker.git
cd ovdp-tracker
```

Откройте терминал в папке проекта. Создайте отдельное окружение и активируйте его:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

В Linux и macOS вместо последней команды выполните `source .venv/bin/activate`.
Если команда `python` недоступна, используйте `python3`.

Установите зависимости и запустите приложение:

```powershell
python -m pip install -r requirements.txt
python -m ovdp_tracker
```

Откройте [http://127.0.0.1:5000/](http://127.0.0.1:5000/) в браузере.
При первом запуске портфель пуст — начните с кнопки **«Добавить облигацию»**.

Пока пользуетесь приложением, оставляйте терминал открытым. Для остановки нажмите `Ctrl+C`.
При следующем запуске откройте папку проекта, активируйте окружение и выполните `python -m ovdp_tracker`.
Повторно устанавливать зависимости для обычного запуска не нужно.

Интернет нужен для установки и загрузки новых сведений из НБУ.
Просматривать сохранённые покупки и вводить облигации вручную можно без интернета.

## Как устроен портфель

**ISIN** — идентификатор выпуска облигаций. Все покупки с одинаковым ISIN объединяются в одну строку портфеля.
Например, если вы купили 10 бумаг одного выпуска, а затем ещё 5 в другом банке, в портфеле будет одна позиция
с 15 бумагами. Даты, цены и банки обеих покупок можно посмотреть внутри неё.

На странице **«Портфель»** выберите **«Валюта выпуска»**: UAH, USD или EUR.
По умолчанию показываются гривневые облигации; при выборе другой валюты список обновляется.
Если нужной позиции не видно, сначала проверьте выбранную валюту.

| Колонка | Что показывает |
| --- | --- |
| ISIN | Выпуск облигаций; нажмите на него, чтобы открыть подробности. |
| Количество | Общий остаток бумаг по всем покупкам выпуска. |
| Купон и дата купона | Ближайший ожидаемый положительный купон на одну облигацию и его дату. |
| Погашение | Плановую дату погашения выпуска. |
| Доходность | Номинальную ставку выпуска из НБУ, если она известна. |

Значение в колонке **«Доходность»** — справочная ставка выпуска. Доходность вашей покупки с учётом её цены
пока не рассчитывается. **«Не указана»** означает, что сведения о ставке отсутствуют.
**«Нет будущего купона»** означает, что подходящего предстоящего купона нет; погашение смотрите отдельно.

## Добавить покупку

Каждую фактически совершённую покупку добавляйте отдельно, даже если такой ISIN уже есть в портфеле.

### Загрузить облигацию из НБУ

1. На странице портфеля нажмите **«Добавить облигацию»**.
2. Оставьте способ добавления **«Подтянуть из НБУ»**.
3. Введите полный ISIN из 12 символов и дождитесь загрузки.
4. Проверьте валюту, номинал, дату погашения и расписание выплат в блоке **«Параметры выпуска»**.
5. Заполните **«Параметры покупки»** по таблице ниже.
6. Нажмите **«Сохранить покупку»**.

После сохранения откроется портфель в валюте добавленной облигации с сообщением **«Покупка сохранена»**.
Загрузка сведений из НБУ сама по себе покупку не сохраняет.

| Поле покупки | Что ввести |
| --- | --- |
| Дата покупки | Дату совершённой покупки. Изначально выбрана сегодняшняя; можно указать прошедшую. |
| Цена одной облигации | Фактическую цену одной бумаги в валюте выпуска. |
| Количество облигаций | Целое положительное число купленных бумаг. |
| Банк | Название банка: выберите из подсказок или введите новое. |

Цену вводите с точкой или запятой, максимум с двумя знаками после разделителя: например, `995,50`.
Она должна быть положительной. Будущую дату покупки указать нельзя.
Название нового банка появится в подсказках после сохранения покупки.

Если загрузка не удалась, проверьте ISIN и нажмите **«Загрузить повторно»**.
При необходимости переключитесь на ручной ввод.

### Ввести облигацию вручную

1. Нажмите **«Добавить облигацию»** и выберите **«Ввести вручную»**.
2. Укажите ISIN, номинал одной облигации и валюту выпуска.
3. Для каждого купона нажмите **«Добавить купон»**, выберите дату и введите сумму **на одну облигацию**.
4. Проверьте календарь и дату погашения.
5. Заполните дату, цену, количество и банк покупки, затем нажмите **«Сохранить покупку»**.

Включайте полный известный календарь, в том числе купоны до вашей покупки. Они останутся в сведениях о выпуске,
но не будут показаны как причитающиеся этой покупке выплаты.
У разных купонов могут быть разные суммы; нулевая сумма допустима. Даты купонов не должны повторяться.

Кнопка **«Сортировать по дате»** упорядочивает строки вместе с суммами.
**«Удалить купон»** убирает выбранную строку. Дату можно набрать с клавиатуры или выбрать в календаре.

Для ручного ввода действуют следующие правила:

- При наличии купонов датой погашения становится дата последнего купона.
- Для облигации без купонов оставьте список пустым и заполните появившееся поле **«Дата погашения»**.
- Сумма погашения одной бумаги равна её номиналу.
- Ставка, дата выпуска и вид облигации вручную не запрашиваются.

Если реальное погашение не совпадает с последним купоном, используйте загрузку из НБУ.
Переключение способов добавления сохраняет введённые вручную строки и параметры покупки,
пока форма остаётся открытой.

### Докупить уже сохранённый выпуск

1. Откройте **«Добавить облигацию»** и введите ISIN, который уже есть в портфеле.
2. Проверьте показанные сохранённые реквизиты и календарь.
3. Укажите параметры новой покупки и сохраните её.

Номинал, валюта и календарь общие для всех покупок одного выпуска, поэтому в повторной покупке они недоступны
для редактирования. Каждая покупка сохраняет собственные банк, дату, цену и количество.
Для докупки без интернета выберите **«Ввести вручную»**: известный ISIN использует сохранённые сведения.

Если данные НБУ отличаются от сохранённых, приложение покажет предупреждение и использует сохранённый вариант.
Добавление покупки не обновляет общие реквизиты выпуска.

## Посмотреть облигацию и её покупки

Нажмите **ISIN** в портфеле. Откроется страница выпуска со следующими сведениями:

- Общие параметры: валюта, номинал, остаток бумаг, погашение и известные сведения о ставке и выпуске.
- **«Общий календарь выпуска»**: даты купонов и погашения с суммой каждого события на одну бумагу.
- **«Все покупки»**: банк, дата, цена, стоимость, исходное количество, остаток и статус каждой покупки.
- **«Причитающиеся выплаты покупок»**: плановые выплаты отдельно для каждой покупки.

Чтобы посмотреть одну покупку, нажмите **«Покупка №…»**.
Стоимость покупки равна цене одной облигации, умноженной на купленное количество.
Например, 10 бумаг по `995,50` дают стоимость `9 955,00` в валюте выпуска.

Для возврата используйте ссылки над содержимым страницы: **«Портфель»**, ISIN и **«Покупка №…»**.
На странице выпуска также есть ссылка в портфель его валюты.
На узком экране широкие таблицы можно прокручивать по горизонтали.

## Читать календарь и выплаты

Общий календарь относится ко всему выпуску. Суммы в нём указаны **на одну облигацию**.
Количество купонов включает весь календарь, в том числе прошлые и нулевые купоны; погашение считается отдельно.

В таблице **«План и факт покупки»** показаны выплаты конкретной покупки:

- **Плановая дата** и тип выплаты — когда ожидается купон или погашение.
- **Количество** — сколько бумаг участвует в этой выплате.
- **План** — ожидаемая сумма на это количество бумаг.
- **Фактическая дата** и **«Факт»** — сведения о получении, если оно уже подтверждено.

Например, купон `80,00` на одну бумагу при количестве 10 даёт плановую выплату `800,00`.
Купон и погашение в один день отображаются отдельными строками.

**«Не подтверждено»** означает, что получение денег не отмечено. Наступление плановой даты само по себе
не подтверждает выплату и не закрывает позицию. Для нулевого купона подтверждение не требуется.
Кнопок подтверждения выплат в текущей версии пока нет.

## Действующие и закрытые позиции

Используйте ссылки **«Действующие позиции»** и **«Закрытые позиции»** внутри портфеля.
При переключении выбранная валюта сохраняется.

Позиция считается закрытой, когда не осталось бумаг ни в одной её покупке.
Если часть покупок закрыта, а в других остались бумаги, выпуск остаётся действующим;
закрытые покупки доступны на странице выпуска. Одна лишь прошедшая дата погашения не закрывает позицию.
Подтвердить погашение через интерфейс пока нельзя.

## Записать продажу

Откройте нужную покупку и нажмите **«Добавить продажу»**. Укажите дату совершённой продажи,
целое количество и цену одной бумаги в валюте выпуска. После сохранения на странице покупки
появятся продажа и её выручка, а остаток и последующие плановые выплаты пересчитаются.
Другие покупки того же выпуска не затрагиваются.

Дата продажи не может быть будущей или предшествовать покупке. Приложение проверяет также
последующие продажи: запись задним числом не должна создавать отрицательный остаток.
В день купона сначала учитывается купон, затем продажа; в день фактического погашения продажа
учитывается до погашения.

## Удалить ошибочную продажу

В карточке покупки найдите нужную продажу и нажмите **«Редактировать»**. Внизу редактора доступна кнопка
**«Удалить продажу»**. В списках и форме новой продажи этой кнопки нет; для диалога нужен JavaScript.
Удаление доступно также для продаж закрытой покупки.

В подтверждении показаны сохранённые ISIN, покупка, дата продажи, количество, цена и выручка с валютой.
**«Отмена»** или Escape закрывают диалог, сохраняя введённые правки. Эти правки не применяются при удалении.
Кнопка **«Удалить сохранённую продажу»** удаляет только выбранную запись без возможности восстановления
и открывает карточку покупки с сообщением об успехе.

Остаток и неподтверждённые выплаты пересчитываются: удаление продажи 3 из 10 бумаг возвращает остаток 10
и увеличивает последующий ожидаемый купон по 80 UAH с 560,00 до 800,00 UAH. Полностью проданная покупка
снова становится действующей, если нет фактического погашения. Подтверждённые суммы и даты выплат сохраняются
без ожидания доплаты; подтверждённое погашение продолжает закрывать покупку. Остальные продажи, покупки,
общие реквизиты ISIN, календарь и банки сохраняются. При ошибке удаления изменения откатываются.
Прибыль и годовые доходности будут использовать исправленную историю после реализации соответствующих расчётов.

## Удалить покупку

В карточке нужной покупки нажмите **«Редактировать покупку»**, затем **«Удалить покупку»** под формой.
Откроется отдельная страница с ISIN, банком, датой, стоимостью покупки и числом удаляемых продаж
и подтверждений выплат. Проверьте выбранную покупку.
**«Отмена»** возвращает к редактированию без изменений.

Кнопка **«Удалить покупку и всю её историю»** навсегда удаляет покупку, её продажи и фактические
подтверждения выплат. Восстановления истории в приложении нет. Удалённые данные исключаются из расчётов;
после удаления откроется портфель в валюте покупки с сообщением об успехе.

Общие реквизиты ISIN, календарь, банки и соседние покупки с их подтверждениями сохраняются.
После удаления последней покупки позиция исчезает из действующего и закрытого портфеля;
при следующей покупке того же ISIN используются сохранённые реквизиты и календарь.

## Ошибки и несохранённые изменения

Если покупка не сохраняется, прочитайте сообщение возле поля, исправьте значение и нажмите
**«Сохранить покупку»** ещё раз. Введённые данные, включая незавершённые строки купонов, сохраняются в форме.

При уходе с изменённой формы по ссылке или через **«Отмена»** появляется выбор:

- **«Остаться»** — продолжить заполнение; нажатие Escape также оставляет форму открытой.
- **«Выйти без сохранения»** — перейти на выбранную страницу и отказаться от изменений.

При обновлении или закрытии вкладки браузер может запросить подтверждение ухода.
Автоматического восстановления черновика после закрытия страницы нет — завершайте ввод кнопкой
**«Сохранить покупку»**. Загрузка данных из НБУ также оставляет несохранённый черновик.

## Что пока недоступно

- Исправление общих реквизитов и календаря выпуска.
- Подтверждение полученных купонов и погашений через интерфейс.
- Расчёт прибыли и доходности конкретных покупок, сводная статистика.
- Планирование будущих покупок.

Разделы **«Выплаты»** и **«Статистика»** в верхнем меню пока неактивны.
Плановые выплаты можно просматривать на страницах выпуска и покупки.
