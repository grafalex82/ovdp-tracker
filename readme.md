# Трекер ОВДП

Небольшой пет-проект для личного учёта облигаций внутреннего государственного займа Украины (ОВДП). Помогает отслеживать покупки, погашения и прибыль, а также планировать будущие вложения.

Планируемые возможности:

- Добавление облигаций с датой покупки, стоимостью, количеством и датой погашения.
- Учёт полученных выплат и расчёт ожидаемой прибыли.
- Статистика прибыли и доходности за выбранные периоды.
- Планирование будущих покупок и ожидаемых поступлений.

Проект рассчитан на одного пользователя. Приоритет — простые и понятные решения, минимум зависимостей и архитектуры, только необходимой для текущих задач.

## Текущее состояние

Реализован минимальный каркас Flask/Jinja: главная страница и локальный CSS.
Учёт облигаций и база данных пока не реализованы; запуск не создаёт пользовательских данных.

## Установка и запуск

Требуется Python 3.11 с pip. Команды выполняются из корня проекта, например
`D:\Projects\OVDPCalculator`. Создавать virtualenv или устанавливать Docker не нужно.

Установите зафиксированные зависимости в используемый Python:

```powershell
python -m pip install -r requirements.txt
```

Для первоначальной загрузки зависимостей нужен интернет. После установки приложение
работает без интернета: шаблоны и стили находятся в пакете, внешние сервисы и CDN не используются.

Запустите приложение:

```powershell
python -m ovdp_calculator
```

Откройте [http://127.0.0.1:5000/](http://127.0.0.1:5000/) в браузере. Должна появиться
страница «Трекер ОВДП» с сообщением о запуске приложения.
Сервер слушает только `127.0.0.1:5000`; debug, интерактивный отладчик и автоматический
перезапуск выключены, в том числе при заданной переменной `FLASK_DEBUG`.

Чтобы завершить работу, нажмите `Ctrl+C` в терминале с запущенным приложением.

Описание требований и изменений хранится в `openspec/`, контекст проекта и правила работы — в `openspec/config.yaml`.
